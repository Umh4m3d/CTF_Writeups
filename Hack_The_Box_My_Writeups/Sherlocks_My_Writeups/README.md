## 📌 About

This repository contains my completed writeups for **Hack The Box Sherlocks** challenges. Each writeup documents the full forensic investigation process, including:

- Initial triage and threat identification
- Malware analysis and threat intelligence
- Network traffic analysis (PCAP)
- C2 infrastructure mapping
- Indicators of Compromise (IoCs)
- Attack chain reconstruction

All investigations are conducted using industry-standard tools such as **Wireshark**, **tshark**, **VirusTotal**, and various command-line forensic utilities.

## 📝 Writeup Template

Each writeup follows a consistent structure:

1. **Scenario** — Challenge description
2. **Executive Summary** — High-level findings
3. **Task Breakdown** — Question → Answer → Methodology
4. **Attack Chain** — IP relationships and attack flow
5. **Indicators of Compromise** — IoC table
6. **Conclusion** — Summary of findings
